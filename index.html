CORE VALUES

為什麼需要「送餐社工」？

送餐服務不僅僅是解決「肚子餓」的問題，更是建立高風險族群與社會接觸的重要紐帶。

獨居安全守護

對於行動不便或獨居長者，送餐員與社工是他們每天少數能接觸的外界窗口，能第一時間發現跌倒、疾病發作等緊急狀況。

個別化營養飲食

針對咀嚼困難、慢性病（如糖尿病、腎臟病）等不同健康狀態，送餐社工會協調廚房調整菜單，確保吃得健康又營養。

社會福利資源串聯

在送餐過程中發掘潛在需求，進一步連結長照資源、醫療補助、居家照顧或心理支持，建構完善的安全網。

DAILY WORK

送餐社工的日常工作內容

從餐點規劃到實際配送管理，社工扮演著不可或缺的指揮與執行角色。

01 / 評估與建檔

個案需求評估

家訪評估案主的經濟狀況、身體障礙程度、咀嚼能力與廚房設備，決定適合的餐點類型與送餐頻率。

02 / 菜單與品管

餐食協調與監督

與營養師及廚房合作，把關食品衛生、營養均衡，並針對特殊飲食需求（如低鈉、碎食）進行微調。

03 / 路線與志工

配送路線與調度

規劃有效率的送餐路線，招募與培訓送餐志工，確保熱騰騰的便當能在黃金時間內送到案主手中。

04 / 關懷與危機

訪視與安全通報

定期複查個案狀況，若遇敲門無回應或身體不適等緊急狀況，立即啟動緊急應變或通報機制。

CHALLENGES & EMOTIONS

工作的挑戰與深刻感動

送餐工作看似規律，但每天都充滿不確定性。面對偏鄉交通不便、極端天候考驗、或是案主突發的健康變化，送餐社工總需要展現高度的應變能力與溫柔堅定的心。

天候與地理障礙

颱風天、大雨或山區道路坍方時，如何安全將餐點送達是一大考驗。

溫暖的笑容是最美回報

「謝謝你們每天都來，這便當讓我覺得自己沒有被世界遺忘。」長輩的一句話，就是撐下去的動力。

「我們送的不只是午餐，而是一份『有人在乎你』的安心感。看著長輩開心地打開飯盒、笑著跟我們打招呼，所有的辛苦都值得了。」
